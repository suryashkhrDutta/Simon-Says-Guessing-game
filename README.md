# 🎮 Simon Says Game

A modern and interactive Simon Says memory game built using HTML, CSS, and JavaScript.

## ✨ Features

* Dynamic sequence generation
* Smooth animations and visual effects
* Sound effects for gameplay interactions
* Difficulty modes
* Responsive modern UI
* Success and game-over feedback effects
* Tutorial support for new users

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🚀 How to Play

1. Press the **Start Game** button
2. Watch the sequence of flashing colors
3. Repeat the sequence in the correct order
4. The sequence gets longer every level
5. Game ends when the wrong sequence is entered
